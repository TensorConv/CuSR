# Inner-constant admit criterion — honest total report

**Scope.** Experiment-1 (the admit/reject criterion for problems that genuinely need
*nonlinear inner* constant optimization), experiment-2 (a frozen constructed corpus
built with it), and the §2.5 application that tightens the positional "34 inner
Feynman" upper bound into a *verified* set. Built with strict TDD + adversarial
red-teaming under zero-tolerance anti-faking discipline. Ground truth is fp64 + scipy
+ independent of any GPU kernel.

All numbers below are regenerated by `make_report.py` → `out/report.json`; the corpus
and Feynman-34 tables by `build_corpus.py` / `run_feynman34.py`. Pre-registration is
frozen in `prereg.py` (written before any `decide()` run; never tuned to pass).

---

## 1. The criterion (5 mechanisms, applied in order)

A problem = (skeleton with free constants, true constant values, sampling domain).
`decide()` runs, in order:

0. **No positional-inner constant** (`count_inner_consts == 0`) → REJECT.
   *outer-only / constant-free.*
1. **Fold** — every positional-inner constant is absorbable by a grammar identity
   into a fixed linear span, so it drops from the inner count after
   `_fold = expand∘expand_trig∘reveal_folds`: multiplicative scale
   `sqrt(c·g)=sqrt(c)·sqrt(g)`, log/exp folds, **trig angle-addition**
   `sin(x+c)=cos c·sin x+sin c·cos x`, **polynomial shift** `(x−c)²∈span{1,x,x²}`
   → REJECT.
1b. **Identifiability** — the inner constants add **no** Jacobian-rank direction
   beyond the outer constants (`inner_adds_rank=False`) → REJECT. Targets inner
   absorbability only, so a redundant *outer* scale (a Scheme-C-split prefactor) does
   **not** veto a genuine inner constant. This is also the SVD numeric-rank
   certificate the strategy doc asked for (§4.3).
2. **Structural-discrete** — every surviving inner constant is within `STRUCT_TOL`
   of a *frozen* canonical, GP-grammar-reachable value (`{0,±1,±2,±0.5,π-multiples,
   ±1/π,±1/2π}`) **and** OLS-outer at those canonical values reaches R²≥τ_high
   → REJECT (reachable without nonlinear CO; ±1 from a subtraction node, π a terminal).
3. **Linear-scaling gap** — ADMIT iff
   `R²_LS(worst over the generic O(1) reference product grid) < τ_low`
   **and** `R²_full > τ_high` **and** `recovery_err < tol`; else REJECT.

**Why three mechanisms** (measured, see `pilot.py`): no single linear-scaling-reference
scheme separates the anchors — `korns_7` needs *worst*-over-grid (a lucky generic decay
≈−0.5 makes max-over-grid 0.999), while `I.8.14`'s structural −1 needs the structural
test (its true value sits *in* the grid, so worst-over-grid is 0.000).

**Division of labour (honesty).** The "admitted ⇒ genuinely needs inner CO" guarantee
is carried by the four **structural** detectors (fold, identifiability, structural,
linear-span), each firing **without** fitting at the true constants. `R²_full` and
`recovery_err` are **construction certificates**: GT-seeded on noise-free data they are
near-tautological (≈1.0 / ≈0 for any well-posed problem), so they certify the admitted
problem is solvable+identifiable at its true constants — they are *not* the load-bearing
anti-cheat and cannot by themselves reject an absorbable problem (the structural
detectors do that first). The GT-seeding is **labelled** (`Verdict.seeding`) and the
blind-solver difficulty is reported separately (`R2_full_random`).

Same disclosure for the **structural** test's R² half: when a true inner constant is
*exactly* canonical (the 32 Feynman rejects), `R²@canon` = `R²@true` = 1.0 trivially on
noise-free data, so that half is near-vacuous and the structural reject is openly
**value-based** ("is the true constant a reachable canonical value?"), not fit-confirmed.
The R² half only does work when a constant is *near* (within `STRUCT_TOL`) but not at a
canonical value — guarding against a coincidental near-canonical value that does not
actually reconstruct the data.

## 3. Threshold sensitivity — no tuning to pass (gate 3)

- **τ_low.** All four hard anchors keep their verdict across the entire frozen sweep
  `{0.10, 0.30, 0.50, 0.70, 0.90, 0.95}` — admits have `R²_LS(worst) ≤ 0.060`, far
  below even 0.10; τ_low=0.70 is safely inside a wide gap (the nearest "linear-scaling-
  suffices" case, nguyen_6, sits at 0.969). τ_low is **not** load-bearing.
- **STRUCT_TOL and the 2 Feynman admits.** The survivors II.11.27/II.11.28 carry a
  **−1/3** polarization factor, which is **4.51%** from the nearest canonical value
  (−1/π=−0.318); with `STRUCT_TOL=0.02` it is non-canonical → admit. The admits survive
  for any `STRUCT_TOL < 0.045`. Crucially, **−1/π is not smuggled to sit near −1/3**:
  removing the 1/π-family from CANON leaves −1/3 still **50%** from canonical, so its
  non-canonicality does not depend on −1/π. −1/3 and −1/π are genuinely distinct
  constants; `STRUCT_TOL=0.02` (< 4.5%) correctly keeps them apart.
- **CANON membership — the load-bearing sensitivity.** Beyond τ_low/STRUCT_TOL (which
  hold the canonical *set* fixed), the Feynman survivor count depends on the set's
  *membership*. This is reported in full in §5: it swings **0–11** across defensible
  reachability sets (2 under the frozen registered set). We do not change the frozen set
  to chase a number; we report the swing and lead with the set-independent statement.

## 5. §2.5 application — Feynman 34 → verified inner (headline, with its load-bearing caveat)

Running the criterion over all 34 positional-inner Feynman problems
(`run_feynman34.py`, `out/feynman34.json`):

**Robust, set-independent fact (the real headline).** Across all 34, the inner constants
are *overwhelmingly simple, grammar-reachable values*: ±1 (subtraction signs), ±0.5 (the
Gaussian-width / sqrt exponent), ±2, and π (phases, spherical/periodic factors). The
**only non-canonical motif in the entire set is −1/3** — the Lorentz/Clausius-Mossotti
polarization factor — appearing in exactly two problems, `II.11.27`
(`x0·x1·x2·x3/(c0 + c1·x0·x1)`) and `II.11.28` (`c0 + x0·x1/(c1 + c2·x0·x1)`). So the
positional "34 inner-constant problems" are, under verification, **almost entirely
Scheme-C inflation** (literal→constant ±1, absorbable scales, π-terminals); there is
essentially **no Feynman inner constant that requires nonlinear CO beyond simple
reachable constants.**

**The count is conditional on the reachability set (and this is the load-bearing
choice).** "Verified-inner" = "inner constant not in the GP-grammar-reachable canonical
set." Where that set's boundary is drawn moves the survivor count, so we report the swing
under defensible alternative sets (frozen default unchanged; `canon_set` passed only for
this sweep):

| canonical (reachability) set | Feynman survivors | admitted ids |
|---|---|---|
| `{±1}` only (subtraction sign the task named) | **11** | I.6.2a/b, I.6.2, I.29.16, I.30.3, I.41.16, II.11.27/28, II.38.14, III.8.54, III.9.52 |
| `{±1,±2,±0.5}` (no π) | **4** | I.41.16, II.11.27/28, III.8.54 |
| **registered (frozen): `{0,±1,±2,±0.5,π-mult,±1/π,±1/2π}`** | **2** | **II.11.27, II.11.28** |
| registered − π-family | **4** | I.41.16, II.11.27/28, III.8.54 |
| registered + simple rationals `{±1/3,±1/4,±2/3,±3/4}` | **0** | — |

**Interpretation.** Under the pre-registered set the answer is **2** (both the −1/3
motif). The honest reviewer-facing question is *"why is ½ reachable but ⅓ not?"* — and
the table answers it transparently: deeming −1/3 reachable gives **0**; admitting only
the ±1 subtraction sign gives **11** (mostly Gaussian widths ±0.5 and π phases, which one
can equally argue are reachable). The result that survives *any* defensible boundary is
the robust statement above: **the Feynman set contains essentially zero inner constants
that need nonlinear CO beyond simple reachable constants — at most the single −1/3
polarization factor (2 problems), and 0 if even small rationals are deemed reachable.**
We therefore lead with that conditional statement, not a bare "2".

## 6. Adversarial validation — findings & resolutions (gate 6)

Two breaks were found and **fixed at root cause** (never by weakening a threshold):

1. **Trig-phase false ADMIT (major; found independently by 2 red-team agents).**
   `c0·sin(x0+c1)` was admitted though it is exactly linear in `{1,sin x0,cos x0}` for
   any phase (angle addition) — the same "absorbable into a fixed linear span" class as
   korns_8, missed because `reveal_folds` never applied trig expansion. **Fix:** `_fold`
   now applies `sp.expand_trig`; genuine *frequencies* (`c·x` inside trig) carry no
   additive angle and are untouched. TDD-locked in `test_criterion_absorption.py`.
2. **Identifiability over-rejection (major; found during my own Feynman-34 audit).**
   The original full-rank check rejected any rank-deficient parameterization, wrongly
   killing genuine inner constants that merely sat alongside a redundant *outer* scale
   (e.g. the Gaussian width in I.6.2a, behind `c0·√c1/√c2`). **Fix:** gate on
   `inner_adds_rank` (do the inner constants add a Jacobian direction beyond the outer
   ones?). TDD-locked in `test_criterion_identifiability.py`. (Verdicts on the 34 were
   unchanged — those problems also reject *structurally* — but the *reasons* are now
   honest.)

**Honesty finding (not a verdict bug).** GT-seeded `R²_full`/`recovery_err` are
near-tautological on noise-free construction data. Resolved by **relabelling** them as
construction certificates (see §1 "division of labour") rather than the anti-cheat —
the structural detectors carry that load. No threshold changed.

**Infra caveat (reported honestly).** Of 6 independent red-team agents, only 2 completed
(both surfacing the trig break); the other 4 died on proxy **stream-idle timeouts** (a
known environment issue, not a criterion problem). Those 4 attack angles
(canon-reverse-engineering, mis-reject-genuine, R²_LS-scheme, counts/Feynman-34) were
**re-run in-process** and found **no further breaks**; their results are in §3/§5 and
the bullets below. This is weaker than 6 fully-independent agents and is stated as such.

**In-process adversarial results (no breaks):**
- All 6 probed genuine non-canonical inner problems ADMIT (no false rejects), including
  the Gaussian-width-with-redundant-outer case the identifiability fix rescued.
- All probed absorbable problems (sin/cos phase, quadratic shift, log shift) REJECT.
- counts: feynman_inner = 34, all `count_inner_consts>0`; `materialize` deterministic;
  both admits carry the genuine −1/3.

## 7. Honest caveats / scope limitations

- **Data-dependence (by design).** "Needs inner CO" is a property of the
  (skeleton, domain) pair, not the skeleton alone. A low frequency on a narrow domain
  (e.g. `cos(1.5·x)` on (−1.5,1.5), <½ period) is near-degenerate and correctly REJECTs
  as linear-scaling-solvable, while `cos(1.5·x)` on (−3,3) ADMITs. Verdicts reflect the
  evaluated data, which is the correct notion.
- **CANON integer boundary.** The canonical set caps integers at ±2 (pre-registered),
  so a genuine frequency of exactly 3 ADMITs while 2 REJECTs as structural. This is a
  pre-registered boundary; it does **not** affect Feynman-34 (no inner constant there is
  3 or another excluded small integer). Extending CANON to ±3, ±4, … would reject more —
  a stated sensitivity, not a hidden one.
- **Genuine canonical-valued constants reject as structural.** `cos(2·x)`, `cos(π·x)`
  reject because 2 and π are grammar terminals — defensible (reachable without CO) but a
  scope choice worth stating.
- **Certificates near-vacuous on clean data** (see §1, §6) — reported, not relied on.
